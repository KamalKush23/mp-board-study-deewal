# School Project

This is a GitHub Pages-ready static website.

## Publish on GitHub
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live website URL.

> Note: The uploaded `Download history.html` is Chrome's Downloads History page, not the original school project source. It cannot be used to reconstruct the original project files.
